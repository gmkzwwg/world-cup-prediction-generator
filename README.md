# 2026 World Cup Prediction Bracket + Full Reference Pages

Pure static GitHub Pages site.

## Pages

- `index.html`: 2026 prediction bracket
- `references/index.html`: reference hub, ordered as overview first, then 2026 → 1930
- `references/all-world-cups.html`: all-time World Cup overview
- `references/2026.html`, `references/2022.html`, `references/2018.html`, `references/2014.html` ... `references/1930.html`: tournament reference pages

## Publish

1. Upload all files to the root of a GitHub repository.
2. Open `Settings → Pages`.
3. Choose `Deploy from a branch`.
4. Select `main` and `/root`.
5. Save.

No Jekyll, Ruby, Actions, or build step is required.
